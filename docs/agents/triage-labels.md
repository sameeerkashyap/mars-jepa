# Triage labels

Use these label strings when a skill refers to a triage role.

| Role | GitHub label | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | A maintainer must assess the issue. |
| needs-info | `needs-info` | More information is needed. |
| ready-for-agent | `ready-for-agent` | The issue is specified and ready for an agent. |
| ready-for-human | `ready-for-human` | A human must implement the change. |
| wontfix | `wontfix` | The issue will not be acted on. |
